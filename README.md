# Synology Photo Tagger

> 以 Apple Silicon 上的 MLX 視覺模型，為 Synology Photos 補上可搜尋、可攜且可驗證的 AI 標籤。

## 目標

這個專案讓使用者先利用 Synology Photos 已有的資料（地點、日期、資料夾、相簿與既有標籤）精準選出候選照片，再以本機 AI 理解影像內容，將可靠的結果寫成可長期保留的照片標籤。

成功不只是「AI 看得懂照片」，而是能在 Synology Photos 中自然搜尋，例如搜尋 `Shopping`、`寺廟`、`夜景` 或 `美食`，並且標籤不會被綁死在某一個資料庫或單一 AI 模型。

## 核心原則

1. **照片檔優先**：支援的圖片格式以 `XMP:Subject` 作為權威標籤欄位；需要相容其他相片軟體時，可同步寫入 `IPTC:Keywords`。
2. **Synology Photos 目錄只負責選片**：優先透過 Photos API 取得候選媒體與既有資訊；必要時才以內部資料庫做唯讀查詢。絕不直接寫入 Synology Photos 的資料庫。
3. **本機、可撤銷、可重跑**：模型輸出、處理版本、原檔修改時間與寫入結果須保留在本專案自己的狀態庫，讓標籤可以審核、撤銷與重新產生。
4. **保留人工標籤**：AI 只新增或更新自己管理的標籤，不能覆寫使用者原有的標籤、描述、評分或拍攝資訊。
5. **詞彙受控**：模型不直接產生無限多同義詞；它先判斷概念與信心分數，再映射成固定、可搜尋的標籤，例如 `shopping` → `Shopping`。

## 使用案例

### UC-01｜依地點挑選，再判斷「購物」

**使用者故事**

> 我想找出所有地點在日本的照片，讓 AI 只替真正與購物有關的照片加入 `Shopping` 標籤。

**流程**

1. 從 Synology Photos 目錄篩出地點國家為日本的照片。
2. 以相片 ID、原檔路徑、修改時間與現有標籤建立候選工作清單。
3. MLX 視覺模型檢查每張照片是否有購物情境，例如商店貨架、商品、價格標籤、購物袋、百貨櫃位或收據。
4. 模型回傳結構化結果：是否為購物、信心分數、可解釋的視覺證據。
5. 高信心結果寫入 `Shopping`，低信心結果加入人工複核清單；不確定或不符合者不改檔。
6. 寫入後確認 Synology Photos 能以 `Shopping` 搜尋到該照片。

**建議閾值**

| 判定 | 動作 |
| --- | --- |
| 信心分數 ≥ 0.85 | 自動新增 `Shopping` |
| 0.60–0.84 | 建立待複核清單，不自動寫入 |
| < 0.60 | 不新增標籤 |

**驗收條件**

- 不是每張「在日本」的照片都被標為 `Shopping`。
- 已有人工作標籤的照片仍可被 AI 補標，而不會被略過或覆寫。
- 每筆變更都能追溯到模型版本、信心分數與處理時間。

### UC-02｜旅遊照片的活動與主題補標

**使用者故事**

> 我已用日期、地點或旅程資料夾找出一批旅遊照，希望補上 `寺廟`、`美食`、`健行`、`夜景`、`購物` 等一致的活動標籤。

**規則**

- 一張照片可有多個標籤，但只輸出可由影像支持的概念。
- 使用固定 taxonomy，避免同一概念同時出現 `Shopping`、`購物`、`逛街` 等難以維護的重複詞。
- 位置、日期與資料夾只用來縮小候選集，不能被當成影像內容的證據。

### UC-03｜補齊既有相片庫，但不重複處理

**使用者故事**

> 我想分批處理多年相片庫；新照片日後也能加入流程，但已處理且原檔未變的照片不應再次耗費推論時間。

**規則**

- 工作狀態以相片 ID／路徑、修改時間、內容雜湊（如啟用）、模型與 taxonomy 版本判定。
- 原檔變更、模型升級或 taxonomy 變更後，可明確選擇重新處理。
- 既有非 AI 標籤不是「已完成」的唯一依據。

### UC-04｜人工複核與安全回復

**使用者故事**

> 我希望先看過不確定的結果，再決定是否寫入；如果模型誤標，也能只移除 AI 加入的標籤。

**規則**

- 複核清單必須顯示縮圖、建議標籤、信心分數與判斷證據。
- 只記錄並撤銷本工具新增的標籤，絕不刪除使用者原有資料。
- 在批次寫入前提供預覽（dry run）與可匯出的變更報告。

## 格式與儲存策略

| 媒體類型 | 主要寫入位置 | 原因 |
| --- | --- | --- |
| JPG / JPEG / PNG / CR2 | `XMP:Subject`；必要時鏡像 `IPTC:Keywords` | 標籤跟隨原檔，可被 Synology Photos 與其他支援標準 metadata 的工具使用。 |
| HEIC / CR3 / X3F | Synology Photos 標籤 adapter + 本專案狀態庫 | 這些格式的標籤不應假設能可靠回寫到原檔。 |
| 影片 | Synology Photos 標籤 adapter + 本專案狀態庫 | General tag 不會回寫到原始影片。 |

> Synology Photos 內部資料庫可協助找出候選媒體，但不是本工具的標籤寫入目標。

## MVP 範圍

第一個可驗證版本只完成 UC-01：

- 選出「地點在日本」的支援圖片。
- 以 MLX 視覺模型判斷 `Shopping`。
- 高信心結果寫入可攜 metadata。
- 產生處理報告與待複核清單。
- 驗證標籤在 Synology Photos 中可搜尋。

暫不納入：影片標註、任意自然語言 taxonomy、大量舊相片全庫掃描，以及任何直接寫入 Synology Photos 資料庫的做法。
